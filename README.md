# Pricing_and_Volatility_Surface

VolSurf — SPY options pricing library + volatility-surface report.

## Headline result

On the committed SPY snapshot (2026-11-16, 10,354 raw quotes, 32 expiries):

- **3,394 contracts (95% of cleaned quotes) invert to a finite American-style
  implied volatility.** Inverting the same mid with the American CRR tree vs
  the European Black-Scholes formula gives IVs that differ by a mean of
  **0.0023 vol points** (median 0.0005, p95 0.0107) — the early-exercise
  premium expressed in vol terms. The pricing model measurably changes the
  volatility you read off the market.
- Three independent pricers (closed-form BSM, CRR binomial, Monte Carlo)
  agree to within stated tolerances; **1,315 tests pass, 93% coverage**.
- Cleaning removed most raw-quote arbitrage violations
  (1,938 → 546 midpoint flags; see `results/arbitrage_report.csv`).

Full findings: [`report/report.md`](report/report.md) ·
non-specialist summary: [`report/summary.md`](report/summary.md) ·
plain-language docs in [`docs/`](docs/).

## Quick start

```bash
.venv/Scripts/python -m pip install -e ".[dev]" -c constraints.txt
```

`constraints.txt` pins the exact direct-dependency versions the library was
developed and tested against (see plan-01); drop the `-c constraints.txt` to
float within the `pyproject.toml` ranges.

### Direct commands (Windows, no `make` required)

```bash
# tests, offline only
.venv/Scripts/python -m pytest -m "not network"

# tests with coverage gate (fail_under = 85)
.venv/Scripts/python -m pytest -m "not network" --cov=volsurf --cov-report=term-missing

# lint + format check
.venv/Scripts/ruff check src tests
.venv/Scripts/ruff format --check src tests
```

### CLI

```bash
# clean a snapshot (PRD §6.5) -> results/cleaned_<date>.csv + cleaning report
.venv/Scripts/python -m volsurf.cli clean data/snapshots/spy_<date>.csv -o results

# quote diagnostics: raw + cleaned side by side -> results/arbitrage_report.csv
.venv/Scripts/python -m volsurf.cli arbitrage data/snapshots/spy_<date>.csv -o results

# volatility surface: iv_table.csv, iv_surface.csv, calendar_diagnostic.csv, figures
.venv/Scripts/python -m volsurf.cli surface data/snapshots/spy_<date>.csv -o results

# MANUAL live snapshot fetch (network, market hours)
.venv/Scripts/python -m volsurf.cli fetch
```

The arbitrage command screens American parity bounds, strike monotonicity,
and call convexity per expiry; `docs/american_parity_bounds.md` explains the
bounds and how to read the flags. Flags are diagnostics, not trade signals.

The surface command inverts cleaned mids to American + Black-Scholes IV,
fits a C0 `LinearNDInterpolator` over (log-moneyness, maturity), and writes
the IV table, surface grid, calendar diagnostic, and figures
(`docs/surface_method.md` explains the interpolation, the 100-step American
choice, and how to read the outputs).

### Makefile targets (optional — needs GNU make)

| target  | purpose                                              |
| ------- | ---------------------------------------------------- |
| setup   | create venv + install package editable               |
| test    | run offline tests with coverage gate                 |
| lint    | ruff check + format check                            |
| fetch   | MANUAL live snapshot fetch (network, market hours)   |
| all     | full pipeline from committed snapshot (offline)      |
| figures | regenerate figures only                              |
| report  | regenerate report only                               |
| clean   | remove caches + generated results                    |

`make` is not required: every target maps to a direct `.venv/Scripts/python ...` command above.

## Repository layout

```
src/volsurf/        pricing + analytics
scripts/            pipeline entry points (run_pipeline, make_figures, make_report)
tests/              pytest suite (markers: network, slow)
report/             report.md (technical) + summary.md (plain-language)
docs/plan/          per-task plan briefs (01..12)
config/             pricing grid + market conventions + cleaning rules
data/snapshots/     committed snapshot CSV + sha256 + provenance metadata
data/raw/           gitignored
results/            CSVs + surface figures (regenerated by make all)
```

Snapshots and result CSVs are committed; raw data is not. Figures are
regenerated offline by `make all` (a few minutes, no network).

## What this project is / is not

**Is:** a from-scratch pricing library (BSM, CRR binomial, Monte Carlo with
antithetic + control variates), an implied-volatility inverter (American
and European), a no-arbitrage screen, a C0 interpolated volatility surface
with SVI slice fits as a cross-check, and a fully reproducible report.

**Is not:** a trading-strategy backtest, a data vendor integration, or a
live feed. One committed snapshot; `make fetch` is the only network step
and is manual. Heston / stochastic-vol calibration is explicitly out of
scope (PRD §16.4).
